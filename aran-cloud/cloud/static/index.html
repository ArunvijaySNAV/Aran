Where it sits

    
Aran sits between your application and everything that stores or receives its data. The same Aadhaar becomes a different token for each destination, so a leak at one place says where it came from and cannot be joined with another.

    
    
What Aran does not do: your application server still receives the plaintext for a moment before it calls Aran. Aran protects what is stored and shared afterwards.
